SENRAN KAGURA ESTIVAL VERSUS still looks great on PC, but the port carries a handful of rendering bugs and limits from its Vita/PS4 roots: textures that shimmer and sparkle, grainy shadows, swimsuits that flicker in zoomed-in shots, and a hard 60 FPS cap. [b]SKEV+[/b] fixes them while the game runs.

The mod is a single DLL (plus a settings file) that the game loads on startup. Every change happens in memory, so your game files and saves are never touched. Before patching anything, SKEV+ checks that the game code is exactly what it expects; if a future update changes something, only that one fix switches itself off and the rest keep working.

[h2]What it fixes[/h2]
[list]
[*][b]Proper mipmapping.[/b] Most of the game's textures ship without mipmaps (the smaller copies a game uses for surfaces further away), and the material shaders were set to always read the full-size texture anyway. That's why wood, decks, ramps and sand crawl and sparkle as the camera moves. SKEV+ generates the missing mipmaps when textures load and lets the shaders use them, with 16x anisotropic filtering on top for crisp surfaces at an angle.
[*][b]Cleaner shadows.[/b] The shadow map resolution goes from 1536 to 3072 for sharper edges, and a precision bug in the soft-shadow maths that left bright speckles flickering inside shadows near objects is corrected.
[*][b]No skin showing through swimsuits.[/b] In long telephoto shots the depth buffer ran out of precision, so skin flickered through clothing. SKEV+ adjusts the camera's near plane to the zoom level, only in those shots, so close-ups, depth of field and shadows stay exactly as before.
[*][b]High frame rate, correct speed.[/b] Play at 120 FPS (or anything up to 360) instead of 60. The game normally speeds up when you do that, so SKEV+ also fixes everything that was tied to the frame count: character animations, finishers, transformations, entrances, defeat scenes, Library replays, the sea and clouds, menu animations, the lottery wheel (which froze above 60 FPS) and controller menu scrolling. Camera animations that flipped upside down for a frame at high FPS are fixed too.
[*][b]Real 4K with DSR/VSR.[/b] In Fullscreen mode the game always rendered at your desktop resolution. SKEV+ lets it render and display at a higher one, such as 3840x2160, using NVIDIA DSR or AMD VSR.
[*][b]Straight to the title screen.[/b] The publisher and middleware logos and the opening movie are skipped.
[/list]

[h2]How do I know it's on?[/h2]
The boot logos disappear and the game opens on the title screen. (On a brand-new save the game still plays its prologue first; that's the game, not the mod.)

For the details, open [b]skmod.log[/b] in the game folder after playing. It's rewritten at every start and lists each fix with its result.

[h2]Tweaking it[/h2]
Open [b]skmod.ini[/b] with Notepad. Each line is one fix with a short explanation next to it, and [b]0[/b] always means "off, like the original game". Changes apply the next time you start the game.

[h2]Steam Deck / Linux[/h2]

[h1]Troubleshooting[/h1]
[b]- One of the fixes isn't doing anything.[/b]
Check [b]skmod.log[/b]. Each fix is marked on, off or SKIPPED. SKIPPED means the game code didn't match what the mod expects, usually after a game update, so that fix stayed off to be safe.

[b]- I'm still at 60 FPS.[/b]
In the game's own options, the frame rate must be set to 60; at 30 you get half of the FrameRate in skmod.ini. V-Sync also caps you at your monitor's refresh rate, so a 60 Hz display can't show more than 60.

[b]- There's no resolution above my monitor's.[/b]
Enable DSR (NVIDIA Control Panel) or VSR (AMD Software) first, and use the Fullscreen screen mode. Windowed and borderless always match the desktop. MaxResolution in skmod.ini sets the target.

[b]- Menus feel slow at high FPS.[/b]
They now run at their original speed. If you liked them faster, set [b]FastMenus=1[/b] in skmod.ini.

[b]- My antivirus flagged dinput8.dll.[/b]
A false positive. Mods that load into a game and change its code in memory trip some heuristic scanners. Restore the file and add the game folder as an exception.

[b]- How do I uninstall?[/b]
Remove [b]dinput8.dll[/b], [b]skmod.ini[/b] and [b]skmod.log[/b] from the game folder. Nothing else was changed.
